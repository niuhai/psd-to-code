# Contributing to DesignMatch

Thank you for your interest in contributing to DesignMatch! We welcome contributions from the community to help improve this project.

## Getting Started

### Prerequisites
- Node.js 16.0 or higher
- npm or yarn
- Git

### Setting up the Development Environment
1. **Fork the repository** on GitHub
2. **Clone your fork** locally
   ```bash
   git clone https://github.com/yourusername/designmatch.git
   cd designmatch
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```
4. **Create a new branch** for your changes
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development Workflow

### 1. Make Changes
- Follow the existing code style and patterns
- Write clear, concise commit messages
- Include tests for new features
- Update documentation as needed

### 2. Run Tests
- Run TypeScript checks
  ```bash
  npm run check
  ```
- Run tests
  ```bash
  npm test
  ```

### 3. Submit a Pull Request
- Push your changes to your fork
  ```bash
  git push origin feature/your-feature-name
  ```
- Create a pull request on GitHub
- Provide a clear description of your changes
- Reference any related issues

## Code Style Guidelines

### TypeScript
- Use TypeScript for all new code
- Follow the existing type definitions
- Use proper type annotations

### React
- Use functional components with hooks
- Follow React best practices
- Keep components small and focused

### CSS
- Use Tailwind CSS for styling
- Follow the existing design system
- Avoid inline styles when possible

### Naming Conventions
- **Files**: Use PascalCase for components, camelCase for utilities
- **Functions**: Use camelCase
- **Components**: Use PascalCase
- **Variables**: Use camelCase
- **Constants**: Use UPPER_CASE

## Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub. When reporting issues:

1. **Bug Reports**
   - Include a clear description of the bug
   - Provide steps to reproduce
   - Include any relevant error messages
   - Specify your environment (OS, browser, Node.js version)

2. **Feature Requests**
   - Clearly describe the feature
   - Explain why it would be useful
   - Provide any relevant examples or mockups

## Code of Conduct

Please be respectful and constructive in all communications. We want to create a welcoming and inclusive community for everyone.
